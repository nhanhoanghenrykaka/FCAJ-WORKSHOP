## 4. VNPay

- Checkout errors now show the backend message instead of only a generic toast.
- Added signed return reconciliation endpoint: `POST /api/payment/vnpay/return`.
- This lets local Docker reconcile a payment after VNPay redirects the browser back, even though VNPay servers cannot call a localhost IPN URL.
- Existing IPN endpoint remains available for public deployments.
- Store prices are USD while VNPay accepts VND, so checkout now uses configurable `VNPAY_USD_TO_VND_RATE` (default demo value `25000`) and validates the same converted amount on return/IPN.
- Forwarded client IP parsing now uses the first address from `X-Forwarded-For`.

### Required VNPay Sandbox settings

Real VNPay Sandbox merchant credentials are not bundled in the project. Create `.env` from `.env.example` and set:

```env
VNPAY_TMN_CODE=...
VNPAY_HASH_SECRET=...
VNPAY_RETURN_URL=http://localhost/payment-result
VNPAY_IPN_URL=http://localhost/api/payment/vnpay/callback
VNPAY_API_URL=https://sandbox.vnpayment.vn/paymentv2/vpcpay.html
VNPAY_USD_TO_VND_RATE=25000
```

After changing environment variables, recreate the backend container.
