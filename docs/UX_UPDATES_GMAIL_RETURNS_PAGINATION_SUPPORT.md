# UX updates: Gmail columns, returns, pagination and support

This revision adds:

- Dedicated Gmail columns in admin customer/order/support tables (Returns already had one).
- Google account sign-up moved below the password/OTP account form and above the existing-account sign-in link.
- Browser-native confirm/prompt dialogs removed in favor of a Shopsflow dialog.
- Returns tab badge for active return/refund workflows.
- Color-coded return actions (approve, reject, receive, refund, waiting/completed states).
- Pagination for long customer account address/wishlist lists, product reviews, and admin per-product review details; existing list pagination remains in place.
- Customer support ticket chats are collapsed by default and can be opened/closed per ticket.
